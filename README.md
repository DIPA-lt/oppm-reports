### Why do I see HTML source code?

If you open a link like `github.com/DIPA-lt/oppm-reports/blob/main/...html`, GitHub shows the **source code** for security reasons.

Use **`dipa-lt.github.io/oppm-reports/...`** instead — that URL renders the page in your browser.
